## 기능 상세

### F-001 로그인 · 작업 공간 진입
- 동작: `/career/` 에서 세션이 있으면 `/me`, 없으면 포털 로그인(`/login?next=/career/`). 개발 서버는 같은 ae:p 계정으로 화면 안에서 로그인.
- 권한: 로그인은 포털(공용 Supabase Auth). 백엔드는 JWT 를 JWKS 로 검증만 한다.

### F-002 오늘
- 출력: 자격증 시험일 · 유효기간(120일 안) D-day, 진행 중 로드맵마다 이번 달 할 일(미완료 5개까지, 바로 체크) · 진행 막대 · 기한 지난 수 · 이번 주 습관 수, 읽지 않은 메시지 3개, 저장한 검색 4개, 이력서 칸 채움.
- 예외: 진행 중 로드맵이 없으면 '로드맵 만들기' 안내. 로드맵을 못 불러오면 그 블록만 오류.

### F-003 채용공고 검색 조건
- 입력: 이름(60자), 키워드(1~10개), 사이트(1개 이상), 근무지 글자, 내 경력(0~40년), 제외어.
- 사이트 묶음: 채용 사이트(원티드 · 점핏 · 사람인 · 잡코리아 · 리멤버 · LinkedIn) · 공공기관(잡알리오) · 기업 채용(SK Careers · 삼성 · LG).
- 잡알리오를 고르면 'NCS 분야 이름(예: 정보통신)을 키워드로' 안내를 띄운다.
- 예외: 없는 사이트 · 빈 키워드는 400.

### F-004 채용공고 결과
- 동작: 키워드마다 사이트를 따로 검색해 공고 ID 로 합치고 근무지 · 경력 · 제외어로 거른다. 사이트 · 조건별 10분 캐시, 사이트당 100건. 사이트끼리 동시에 묻고 한 곳이 실패해도 나머지는 보인다.
- 출력: 사이트별 섹션(목록 · 키워드별 검색 링크 · 안내) 또는 '한 목록'(모든 사이트 공고를 마감 임박순, 사이트 이름표, 링크만 사이트는 위 '직접 확인할 곳'에 링크와 안내). 보기는 브라우저에 기억.
- 링크만: 잡코리아 · LinkedIn · SK Careers(검색어 링크), 리멤버 · 삼성 · LG(채용 첫 화면 하나 + '키워드를 직접 입력' 안내), 키 없는 사람인 · 잡알리오.

### F-005 자격증 관리
- 준비 중: 시험일 D-day(탭에 가장 가까운 D-day). 취득: 점수 · 자격번호 · 유효기간(120일 안이면 경고). 취득한 것만 공개 이력서에 나간다.

### F-006 이력서 편집
- `profiles.resume` jsonb 한 칸에 인적 사항 · 소개 · 경력 · 학력 · 기술 · 자격. 공개 여부와 공개 주소(slug, 처음에는 이메일 아이디).

### F-007 프로젝트 관리
- 업무 · 개인 구분, 기간, 설명, 기술, 링크, 비공개(주인에게만), 정렬 순서.

### F-008 PDF 저장
- 인쇄 스타일로 이력서 종이만 남긴다 (탭 · 머리 · 편집 도구 숨김).

### F-009 공개 이력서
- 비공개 프로필 · 비공개 프로젝트 · 준비 중 자격 · 알림 받을 곳은 방문자에게 보이지 않는다. 주인이 열면 위에 '작업 공간으로 돌아가기' 띠.

### F-010 메시지 남기기
- 입력: 이름 · 메일 · 전화 · 본문(2000자). 숨은 칸(봇), IP 당 시간당 횟수 제한(`CONTACT_PER_HOUR`).
- 출력: 받은 메시지함에 저장, 설정된 채널로 알림. 알림이 실패해도 메시지는 남는다.

### F-011 받은 메시지
- 최신순 목록, 읽음 · 안 읽음, 지우기. 탭에 새 메시지 수.

### F-012 알림 설정
- 메일 · 문자 받을 곳과 켜기/끄기. 서버에 설정이 없는 채널은 꺼진 것으로 보인다. 문자는 하루 상한(`SMS_DAILY_LIMIT`).

### F-013 로드맵 목록 · md로 만들기
- 목록: 진행 중(오늘이 기간 안) · 예정 · 끝남. 카드에 기간 · 구간 수 · 진행률 · 완료/전체 · 기한 지남. 진행 중이 하나뿐이면 탭을 누를 때 바로 그 로드맵을 연다(`?all=1` 이면 목록).
- 입력: md 파일(.md · .txt, 200KB) 끌어 놓기 · 고르기, 또는 붙여 넣기. Claude 답을 코드 블록(```)째 붙여 넣어도 읽는다.
- md 형식: `---` 머리말(title 필수, period `YYYY-MM-DD ~ YYYY-MM-DD` 또는 `YYYY-MM ~ YYYY-MM`, lead, categories), `## 구간 (YYYY-MM ~ YYYY-MM)` + `> 목표:`, `### YYYY-MM`(또는 `YYYY년 M월`), `- [ ]` / `- [x] [분류] ★ 할 일 (완료 YYYY-MM-DD)`, `## 매주 습관` + `- 이름`. 머리말 대신 `# 제목` 도 된다.
- 미리보기: 구간 · 달 · 할 일 · 마일스톤 · 습관 · 분류 수, 줄 번호가 붙은 오류 · 경고. 오류가 있으면 저장 버튼이 꺼진다. 경고 줄은 건너뛴다.
- 규칙: 기간이 없으면 할 일의 달로 정한다. 날짜 없는 `[x]` 는 오늘 완료. 분류는 머리말 + 할 일의 분류(6개까지). 구간은 12개까지, 겹치면 오류. 할 일 500개 · 300자, 습관 10개.
- 권한: 주인만. DB 는 `career.roadmaps` · `roadmap_items` · `roadmap_habits`, 브라우저 키 접근 불가.

### F-014 로드맵 상세 · 할 일 체크
- 출력: 제목(형광펜) · 기간 · 몇 개월째 · lead. 구간 카드(이름 · 기간 · 목표 · 진행 막대 · %), 다 끝났거나 지금이 아닌 구간은 접힘. 구간 안은 달 묶음('YYYY년 M월까지' + 완료 / 이번 달 / 기한 지남 배지 + 완료/전체). 어느 구간에도 안 드는 달은 '구간 밖'.
- 동작: 체크하면 바로 화면에 반영하고 서버가 완료일(한국 날짜)을 붙인다. 실패하면 그 할 일만 되돌리고 이유를 띄운다 (여러 개를 빠르게 체크해도 서로 덮어쓰지 않는다). 거르기(전체 · 미완료만 · 분류). 구간마다 할 일 추가(달 · 분류 · 내용). 할 일 고치기(내용 · 달 · 분류 · ★), 지우기(두 번 눌러 확인). 처음 열 때 이번 달 묶음으로 스크롤.
- 정보 고치기: 제목 · 한 줄 설명 · 시작일 · 종료일 · 분류(6개) · 구간(이름 · 시작/끝 달 · 목표). 분류를 빼면 그 분류의 할 일은 '분류 없음'이 된다. 로드맵 지우기(할 일 · 습관 함께, 실패하면 이유를 띄움).
- 접기: 다 끝난 구간과 아직 안 온 구간만 접는다. 지나간 구간에 밀린 일이 있으면 펼쳐 둔다.
- 예외: 남의 로드맵 · 없는 id 는 404.

### F-015 로드맵 통계
- 요약 4칸: 전체 진행률(% · 완료/전체 · 막대), 이번 달(완료/전체 · 남은 일), 기한 지난 미완료(있으면 경고색 + '미완료만 보기'), 다음 마일스톤(가장 이른 미완료 ★).
- 계획 대비: 기간 경과율과 달성률 막대, 차이가 3%p 이상이면 '계획보다 N%p 앞서/뒤처져 있어요'.
- 분류별 · 구간별 달성률 막대 (분류 이름표 색 = 분류 순서대로 탭 색). 분류 밖 할 일은 '분류 없음'.
- 작업 공간의 로드맵 탭에 진행 중 로드맵의 기한 지난 수.

### F-016 매주 습관
- 이번 주(ISO 주, 한국 날짜 기준) 체크 · 해제, 최근 12주 칸, 누적 주 수. 습관 추가(10개까지) · 지우기(두 번 눌러 확인).
- 예외: 없는 주(예: 2027-W53)는 400.

### F-017 Claude 부탁 글 · md 내보내기
- 부탁 글: '새로 만들기'(목표 · 시작일 · 종료일 · 지금 상황 · 분류를 넣은 글) 또는 '기존 체크리스트 바꾸기'(HTML · 백업 JSON 을 함께 올리는 글). 두 글 모두 md 형식 설명을 담는다. 복사 · Claude 열기. 서버는 Claude 를 부르지 않는다.
- 내보내기: 같은 md 형식(체크 · 완료일 포함, 습관 주별 기록은 빠짐), 파일 이름은 제목. 다시 올리면 같은 로드맵이 된다.

### F-018 잡알리오 공고
- 출처: 공공데이터포털 '공공기관 채용정보 조회서비스' 목록(`apis.data.go.kr/1051000/recruitment/list`), 진행 중 공고를 100건씩 최대 3쪽(300건).
- 입력 변환: 키워드가 NCS 대분류 이름이면 NCS 분야 코드(정보통신 = R600020), 아니면 공고 제목 포함. 근무지는 시·도 코드(광주 · 전남 = 전남광주통합특별시 R3027). 채용구분은 API 가 한 값만 받아서 요청에 넣지 않고, 받은 공고의 채용구분(신입 · 경력 · 신입+경력)을 경력 범위로 바꿔 내 경력으로 거른다.
- 출력: 기관명 · 제목 · 근무지역 · 채용구분 · 마감일 · 고용형태 · NCS 분야 이름표, 원문 주소(없으면 잡알리오 상세).
- 예외: 인증키(`JOBALIO_SERVICE_KEY`)가 없으면 잡알리오 검색 링크만. 인증 오류는 그 사이트 칸에만 표시.

### F-019 테스터 계정 잠금 · 정리
- 대상: 포털의 공용 테스터 계정(`auth.users.raw_app_meta_data.role = 'tester'`). 판단은 DB 의 `auth.users`를 읽는다(앱은 1분 캐시). `GET·PUT /me/profile`(F-006) 응답에 `is_tester`.
- 잠금: [migrations/0003_tester.sql](../../backend/migrations/0003_tester.sql) 의 트리거. 기본 데이터(`tester_baseline_at` 이전에 만든 행 — 프로필 · 프로젝트 · 로드맵 · 할 일 · 습관)를 고치거나 지우면 403 `tester_locked` "기본 데이터는 테스터가 바꿀 수 없어요". 테스터가 넣는 행의 `created_at`은 지금으로 고정된다. 편집 중(`tester_editing`)에는 꺼지고, 그동안 정리는 편집을 시작하기 전(`tester_edit_started_at`)에 남은 데이터만 지운다.
- 막은 기능: 채용공고(F-003 · F-004 · F-018: `/me/job-sites` · `/me/job-searches*` · `…/results`), 받은 메시지(F-011), 알림 설정(F-012), 테스터 공개 페이지에 메시지 남기기 → 403 `tester_blocked` "테스터 계정에서는 쓸 수 없는 기능이에요". 웹은 채용공고 · 메시지 탭과 오늘 화면의 두 블록을 숨기고, 주소로 들어오면 안내를 보여 준다. DB 트리거도 같은 쓰기를 막는다(AE402).
- 정리: `POST /me/tester/reset`(포털이 로그아웃 직전에 부름) · 매일 04:00(한국) `pg_cron` → `career.tester_reset`. 기준 시각 이후에 만든 로드맵(기본 로드맵에 새로 넣은 할 일 · 습관 포함) · 프로젝트 · 검색 조건 · 메시지를 지운다. 프로필은 남는다. 테스터가 아니면 `{ deleted: 0 }`.
